# VK Conference Bot — Python + SQLite

Бот-модератор конференций VK с уровнями доступа 0–4, историей предупреждений, мутами, локальными банами, антифлудом и связями локализаций. Все настройки и история хранятся в SQLite; файл `bot.db` создаётся при первом запуске.

## Возможности

- Уровни 0–4: Пользователь, Модератор, Ст. Модератор, Гл. Модератор, Создатель.
- `/q` с callback-кнопками подтверждения/отмены и сбросом уровня после подтверждения.
- `/help 0-4`, `/time`, `/mute`, `/unmute`, `/pin`, `/unpin`, `/warns`, `/warnlist`.
- `/warn`, `/unwarn`, `/kick`, `/admins`, `/get`, `/domain` (также скрытый псевдоним `/domen`), `/domaindelete`, `/searchdomain`.
- `/ban`, `/unban`, `/banlist`, `/arang 0-3 [-l]`, `/amode`, `/arangrules add|remove|info`.
- `/nt 0 текст` — личный вызов участников одной конференции; `/nt 1 текст` — вызов участников всех конференций локализации.
- `/comment` и `/comments` — комментарии о пользователях, доступные только внутри локализации.
- `/pm` показывает названия локальных конференций вместе с локальными ID и VK ID; `/pm ID текст` отправляет сообщение в выбранную конференцию.
- `/execute` — последовательное выполнение нескольких команд (уровень 4).
- `/time` всегда показывает московское время; команды в отредактированных сообщениях также обрабатываются, если версия vkbottle поддерживает событие `MESSAGE_EDIT`.
- `/localcreate`, `/localdelete`, `/localjoin`, `/localleave`, `/lkick`, `/lban`, `/unlban`.
- 20 сообщений за 10 секунд создают мут на 15 минут.
- Каждые два устных предупреждения конвертируются в одно основное. `/warn @id количество причина` выдаёт сразу несколько устных предупреждений; `/unwarn @id oral количество` снимает устные предупреждения. При накоплении трёх основных предупреждений бот выдаёт бан на 15 дней и сбрасывает счётчики. `/warns` показывает активные предупреждения, `/warnlist` — историю с постраничной навигацией.
- `/ban @id -1 причина` создаёт перманентный локальный бан.
- `/banlist [@id] [страница]` показывает историю блокировок (в локализации объединяет записи всех подключённых бесед). `/comments @id [страница]` листает комментарии; истории выводятся по 10 записей, комментарии — по 3 на страницу.
- У историй блокировок, предупреждений и комментариев есть inline-кнопки для перелистывания страниц.
- `/ls @пользователь текст` отправляет личное сообщение от сообщества; работает только из локализованной конференции, если адресат состоит хотя бы в одной конференции этой локализации.
- `/restart` перезапускает процесс, сохраняя базу данных. `/cmdplus @пользователь /команда` и `/cmdminus @пользователь /команда` выдают/отзывают персональный доступ к конкретной команде в текущей конференции. Команды, которые могут менять права или перезапускать бот, передать таким способом нельзя.
- `/raspnew Название | Описание`, `/rasppublic ID_конференции ID_объявления ДеньНедели ЧЧ:ММ [-c]`, `/raspedit`, `/raspedittime`, `/raspdelete`, `/raspinfo` и `/raspcycle` управляют объявлениями и расписанием. Список дней недели — понедельник–воскресенье (также принимаются `пн`, `вт`, `ср`, `чт`, `пт`, `сб`, `вс`); время указывается по Москве. Без `-c` публикация одноразовая, с `-c` повторяется еженедельно.
- Смена владельца синхронизирует уровень 4, если VK API возвращает данные владельца.

## Установка

Требуется Python 3.10+ (рекомендуется 3.11/3.12).

1. Создайте сообщество VK и включите сообщения сообщества.
2. В настройках API включите Long Poll и событие `message_new`. Боту нужно получать сообщения в беседах.
3. Создайте токен сообщества с доступом к сообщениям. Не публикуйте токен и не коммитьте `.env`.
4. Установите зависимости:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

5. Скопируйте `.env.example` в `.env` и укажите `VK_GROUP_TOKEN`.
6. Добавьте бота в нужные беседы. Для удаления чужих сообщений, закрепления и исключения участников у бота должны быть необходимые права в каждой беседе.
7. Запустите:

   ```bash
   python bot.py
   ```

## Формат команд

Упоминание можно передать как `@id123 (Имя)` или `[id123|Имя]`. Большинство команд также поддерживают ответ на сообщение пользователя.

Длительность мута указывается только целым числом минут: `15` означает 15 минут. Для `/ban` доступны `15м`, `2ч`, `3д`, `45s` или `120` (число без суффикса считается минутами); `-1` означает перманентный бан.

Примеры:

```text
/q
/mute @id123 15 флуд
/unmute @id123 причина снятия
/pin                         # ответом на сообщение
/warn @id123 нарушение правил
/unwarn @id123 1
/kick @id123 спам
/ban @id123 -1 повторный спам
/unban @id123
/arang @id123 3 -l
/domain @id123 red-team
/nt 0 Всем привет! Зайдите, пожалуйста, в конференцию.
/nt 1 Вызов всех участников локализации!
/pm
/pm 123456 Привет из другой беседы
/get -y @id123
/banlist
/warnlist @id123 2
/comment @id123 Важная информация для модерации
/comments @id123 2
/ls @id123 Привет! Напиши мне, пожалуйста.
/cmdplus @id123 /get
/cmdminus @id123 /get
/raspnew "Важное объявление" Текст объявления для участников
/rasppublic 1 1 пт 18:30 -c
/raspinfo 1
/raspcycle 1 OFF
/restart
/execute
/time
/admins
/searchdomain red-team
/arangrules add 2 /lkick
/arangrules info /lkick
/localcreate Main
/localjoin Main
/lban @id123 нарушение правил
/unlban @id123
```

`/localdelete Название` работает только в главной беседе соответствующей локализации. `/localleave Название` работает только в подключённой, не главной беседе.

## Важные ограничения VK API

- **Мут и `/amode` — программная модерация.** Бот отслеживает сообщения и пытается удалить сообщения замьюченных участников и пользователей без админского уровня в режиме `/amode`. Это не системное ограничение возможности отправки сообщения на стороне VK: для удаления нужны права модерации и доступность `messages.delete`.
- **Баны хранятся в SQLite**, поскольку отдельный универсальный API-список банов произвольной беседы не предполагается. Если заблокированный пользователь снова появляется в беседе, бот пытается удалить его. Чтобы работало надёжно, включите получение сервисных сообщений о приглашении участника и дайте боту необходимые права.
- Бот не может гарантированно исключить участника, если VK не разрешает токену сообщества удалять его из беседы. В этом случае причина ошибки отправляется в чат/лог.
- При выходе через стандартный интерфейс VK бот обрабатывает сервисное событие, сбрасывает уровень и отмечает необходимость повторного приглашения. Если API не прислал сервисное событие, это событие невозможно достоверно восстановить задним числом.
- Стандартный VK API не предоставляет обычному боту достоверную дату регистрации аккаунта пользователя. Поэтому `/get` явно показывает ограничение API и вместо выдуманной даты сообщает, когда пользователь впервые был замечен ботом.
- Статистика активности считается с момента, когда бот увидел пользователя или получил от VK дату входа; это не гарантированно полная история за всё время существования беседы.
- Синхронизация Создателя зависит от того, предоставляет ли API признак владельца среди участников. После передачи владельца бот обновит уровни при следующей синхронизации (до 60 секунд кеша).

## Безопасность и эксплуатация

- Не загружайте `.env` или `bot.db` в открытые репозитории.
- Рекомендуется запускать процесс под отдельным системным пользователем и регулярно делать резервные копии `bot.db`.
- Если меняете права команд, сначала проверьте `/arangrules info /команда`. У `/arangrules` есть встроенная защита: команда всегда доступна только уровню 4.


## Локализации: ID и обмен сообщениями

Каждой подключённой беседе назначается собственный числовой ID, начиная с 1 и далее с выбором первого свободного номера. При обновлении старые случайные локальные ID автоматически перенумеровываются. Узнать ID можно после `/localcreate` или `/localjoin`; список доступен через `/pm`. Для передачи сообщения в другую беседу локализации используйте `/pm ID текст`. Команда `/nt 0 текст` отправляет вызов участникам одной беседы, а `/nt 1 текст` — уникальным участникам всех бесед локализации; в личном сообщении указываются локализация, конференция-источник и отправитель. Команда покажет счётчик доставки и причины отказов VK. Фактическая доставка зависит от настроек приватности VK и возможности пользователя получать сообщения от сообщества. Команда `/get -y` отображает время нахождения в месяцах и оставшихся днях и не является отдельной командой в `/help`.

Файл базы данных открывается по стабильному пути относительно папки проекта (существующая база в текущей рабочей папке также сохраняется при переходе со старой версии). API-запросы направляются на `api.vk.ru`; если соединение с этим доменом не удаётся, включается совместимая попытка через старый домен.

Команда `/arang @пользователь 3` выдаёт третий уровень. Суффикс `-l` в конце команды, например `/arang @id123 2 -l`, применяет уровень ко всем беседам текущей локализации. Настройки уровней команд из главной беседы наследуются дочерними беседами, если в дочерней не задано собственное правило.
